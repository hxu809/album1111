# David Tao 陶喆 - 个人介绍网页

这是一个介绍华语 R&B 教父陶喆（David Tao）的精美网页。

## 项目简介

本项目是一个响应式的单页面网站，展示了陶喆的音乐生涯、代表作品和荣誉奖项。

## 功能特点

- **响应式设计**：完美适配桌面、平板和手机设备
- **现代化UI**：使用渐变色、阴影和动画效果
- **流畅交互**：平滑滚动、悬停效果和加载动画
- **内容丰富**：包含个人简介、音乐生涯时间线、专辑作品和荣誉奖项

## 页面内容

### 1. 关于陶喆
- 个人简介和背景
- 基本信息卡片

### 2. 音乐生涯
- 时间线展示重要里程碑
- 从 1997 年首张专辑至今的发展历程

### 3. 代表专辑
- 5 张经典专辑介绍
- 包含发行年份和代表歌曲

### 4. 荣誉奖项
- 金曲奖获奖记录
- 其他重要音乐奖项

## 技术栈

- **HTML5**：语义化标签
- **CSS3**：Flexbox、Grid 布局、CSS 变量、动画效果
- **JavaScript (Vanilla)**：
  - Intersection Observer API（滚动动画）
  - 平滑滚动
  - 交互效果

2. 直接在浏览器中打开 `index.html` 文件
3. 无需任何构建工具或服务器

## 特色功能

### 响应式断点
- 桌面端：> 968px
- 平板端：768px - 968px
- 手机端：< 768px
- 小屏手机：< 480px

### 交互效果
- 导航栏平滑滚动
- 专辑卡片悬停放大效果
- 滚动加载动画
- 页面加载淡入效果
